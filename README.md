# এক ইনবক্স

WhatsApp, মেসেঞ্জার আর ইনস্টাগ্রামের মেসেজ এক জায়গায় দেখা ও রিপ্লাই দেওয়ার অ্যাপ।

## ফাইলগুলো
- `server.js` : সার্ভার (Meta-র মেসেজ নেয়, রিপ্লাই পাঠায়)
- `index.html` : অ্যাপের পেজ
- `.env.example` : যে তথ্যগুলো লাগবে তার তালিকা

## ধাপ ১: নিজের কম্পিউটারে চালিয়ে দেখো
1. nodejs.org থেকে Node.js (20 বা তার বেশি) ইনস্টল করো।
2. এই ফোল্ডারে টার্মিনাল খুলে লেখো: `npm install`
3. `.env.example` কপি করে `.env` নাম দাও, আর `ADMIN_PASSWORD` ও `VERIFY_TOKEN` ভরো।
4. `npm run dev` চালাও।
5. ব্রাউজারে `http://localhost:3000` খুলে পাসওয়ার্ড দিয়ে ঢোকো।

## ধাপ ২: ইন্টারনেটে চালু করো (Render, ফ্রি)
1. এই ফোল্ডার GitHub-এ আপলোড করো (`.env` আপলোড করবে না)।
2. render.com এ GitHub দিয়ে ঢুকে New > Web Service বেছে নাও, তোমার রেপো দাও।
3. Build Command: `npm install` | Start Command: `npm start`
4. Environment থেকে `.env.example`-এর সব নাম ও মান বসাও।
5. চালু হলে একটা লিংক পাবে, যেমন `https://তোমার-নাম.onrender.com`।

## ধাপ ৩: Meta-কে সার্ভার চেনাও
1. Meta অ্যাপ > WhatsApp > Configuration > Webhook এ Edit চাপো।
2. Callback URL: `https://তোমার-নাম.onrender.com/webhook`
3. Verify Token: `.env`-এ যেটা দিয়েছ সেটাই।
4. Verify and save চাপো, তারপর `messages` ফিল্ড Subscribe করো।
5. তোমার ফোন থেকে টেস্ট নম্বরে একটা মেসেজ পাঠাও। অ্যাপে এসে যাবে।

## মেসেঞ্জার ও ইনস্টাগ্রাম
পরের ধাপ। Meta অ্যাপে Messenger ও Instagram প্রোডাক্ট যোগ করে Page Access Token নিতে হবে। এটা WhatsApp কাজ করার পর করো।

## মনে রাখার কথা
- ফ্রি Render-এ ডাটা ফাইল মাঝে মাঝে মুছে যেতে পারে। টেস্টের জন্য ঠিক আছে। আসল ব্যবহারে Supabase-এর মতো ডাটাবেস বসাতে হবে।
- ফ্রি Render কিছুক্ষণ কেউ না ঢুকলে ঘুমিয়ে পড়ে, প্রথম মেসেজে একটু দেরি হতে পারে।
- কাস্টমার মেসেজ করার ২৪ ঘণ্টা পর্যন্ত সাধারণ রিপ্লাই দেওয়া যায়।
- অস্থায়ী WhatsApp টোকেনের মেয়াদ কিছুক্ষণেই শেষ হয়। দীর্ঘমেয়াদি সিস্টেম ইউজার টোকেন বানানো লাগবে।
